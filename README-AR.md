# تطبيق الفرقان — حزمة أولية

هذه الحزمة تنظّم 10 شاشات HTML المصدّرة من Google Stitch داخل مشروع Capacitor مبدئي.

## مهم
- `www/index.html` صفحة فهرس تتيح فتح التصاميم العشرة.
- ملفات `www/screens/` هي صفحات التصميم الأصلية.
- هذه الحزمة ليست APK جاهزًا، ولا تضمن أن وظائف الأزرار أو الصوت أو البحث أو بيانات القرآن تعمل؛ إنها نقطة بدء للبناء.
- بعض التصميمات تعتمد على خطوط أو Tailwind عبر الإنترنت، لذلك قد لا تظهر كل التفاصيل دون اتصال.
- لا تعتمد التطبيق للنشر قبل مراجعة نصوص القرآن الكريم ومصادرها واختبار كل الوظائف.

## بناء APK من الهاتف عبر GitHub
1. أنشئ مستودعًا جديدًا على GitHub وارفع جميع محتويات هذه الحزمة إليه.
2. افتح تبويب Actions في المستودع واسمح بتشغيل GitHub Actions إذا طُلب ذلك.
3. شغّل سير العمل `Build Android APK` من زر Run workflow.
4. بعد نجاحه، افتح نتيجة التشغيل ونزّل Artifact باسم `furqan-debug-apk`.
5. فك ضغط الـ Artifact لتحصل على `app-debug.apk` ثم انقله إلى الهاتف وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

إذا فشل البناء، أرسل نص الخطأ كاملًا.
